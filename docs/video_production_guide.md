## 1. 한 줄 스토리

물류센터는 대부분 AMR·로봇팔·컨베이어·소터가 자동으로 처리하지만, 갑자기 우선순위가
바뀌는 예외 상황은 결국 사람이 판단해야 한다. 기존엔 사무실 담당자가 현장에 **전화로
요청**해야 했지만, 우리 Control Tower를 쓰면 담당자가 **웹으로 직접** 원격 개입할 수
있다 — 영상은 이 Before → After를 보여준다.

정확한 컷 길이 배분은 아직 미확정 (5장 참고).

## 3. 촬영 세션 3개

### 세션 A — 정상 운영 (1~3번 비트, 원테이크)
- `main_mission.py` 실행, GUI에서 만든 고정 카메라 여러 개를 수동으로 전환하며 OBS로
  연속 녹화
- AMR 이동 → P3020 적재까지 한 실행 안에서 이어짐 (재시작 없이 카메라만 이동)
- 주의: `PARCEL_REGISTRY`에 박스가 1개만 설정돼 있어 이 세션에서는 박스 1개만 등장함

### 세션 B — 소터 데모 (4번 비트, 완전 별도 실행)
- `origin/hiw_sorter_merge`의 `docs/sorter_merge/reference_hwi_new_sorter/sorter_demo.py`를
  가져와서 실행 (AMR/P3020 없이 박스만 계속 랜덤 스폰하는 격리된 씬)
- 랜덤 시드 고정 불필요 — 30~40초 넉넉히 녹화 후 편집에서 3트랙 모두 갈라지는 예쁜 구간만
  트리밍해서 사용
- 이 브랜치엔 아직 이 파일이 없으므로 새로 가져와야 함 (새 파일 추가라 다른 작업과 충돌 없음)

### 세션 C — 관제 개입 시나리오 (5번 비트 2~5번 서브샷, 수동 셋업)
1. `main_mission.py` + 관제 스택(`compose.yaml`, `scripts/run_control_tower_adapters.sh`) 실행
2. 대시보드(`/`)에서 `MAIN_CONVEYOR` 카드 **STOP** 클릭 (STOPPED/빨강 확인)
3. `AMR_IN` 카드 → `/amr` 페이지 → **Jog Control**로 AMR을 우선순위 위치가 아닌 곳으로 미리 이동
4. 두 상태 확인되면 **녹화 시작**
5. 촬영 순서: 대시보드 재접속 → `/amr`에서 Jog로 우선순위 위치 이동 → 대시보드에서
   `MAIN_CONVEYOR` **START** 클릭(빨강→초록) → Isaac Sim 와이드샷 마무리
- 참고: 대시보드 "CREATE MISSION" 폼에 이미 있는 region 선택지(`A/B/C/UNKNOWN`)를
  알림 문구의 "B구역"과 맞추면 3중 매칭(아래 4장)이 자연스러워짐
- **디바이스를 태블릿에서 노트북으로 변경(2026-08-27)**: 실제 관제 조작 환경이 마우스
  기반 노트북/데스크톱이라 이쪽이 더 사실적이고, 프론트엔드가 반응형이 아니라서 태블릿에
  못 띄우던 문제(구 10장)도 노트북에서는 애초에 발생하지 않음 → 목업 프레임 합성 과정이
  아예 사라짐. 대시보드 진입(5-2)부터 Jog(5-3, 단 Isaac Sim 화면은 별도)와 컨베이어
  START(5-4)까지 **같은 노트북 화면 녹화 하나로 이어서 찍어도 됨** (더 이상 별도 소스로
  나눠 합성할 필요 없음)

세션 A와 C는 초기 상태(컨베이어/AMR 위치)가 반대라서 반드시 분리해서 촬영.

## 4. 핵심 연출 장치 — "3중 매칭"

①노트북 알림의 구역명 = ②대시보드에 뜨는 구역명 = ③물류센터 와이드샷 속 그 구역.
세 곳을 같은 이름/위치로 매치컷하면 "지금 이 순간의 실제 상황"이라는 인과관계를
자막 없이도 시각적으로 증명할 수 있음.

## 5. 편집 계획 — CCTV 하드컷 스타일

- 모든 클립에 비네트 + 채도 낮춤 필터를 동일하게 적용 (감시카메라 룩)
- 컷은 디졸브 없이 **하드컷 유지** — 이게 오히려 CCTV다움을 살림
- 3번(P3020)→4번(소터) 사이 박스가 다른 것은 "서로 다른 카메라가 다른 시점을 비춘다"는
  컨셉으로 자연스럽게 커버됨
- 5번 비트 1~2번 서브샷(노트북 알림)만 서사 연출(AI 생성/그래픽)이고, 2번 이후(대시보드
  진입~컨베이어 START)는 전부 실촬영 그대로 사용 — 노트북으로 바꾼 뒤로는 목업 프레임
  합성이 필요 없어짐
- 툴: 촬영 OBS Studio, 편집 Shotcut (또는 ffmpeg 스크립트로 필터+컷 자동화)
- 나레이션/자막 없음 — 그림만으로 전달

## 6. 아직 안 정해진 것 (리스크)

- 비트별 정확한 컷 길이 배분
- "긴급 우선순위 요청"이라는 원인을 자막 없이 전달하는 것 — 3중 매칭으로 상당 부분 해결되나
  최종 검증 필요
- 총 길이가 65~70초로 늘어난 것에 대한 최종 승인 (60초 목표 대비)
- 평가표 최고 배점 항목인 "동적 대응/정량 검증"(35점)이 현재 영상에 없음 — 영상 또는
  발표자료 중 하나에는 반영 필요 (별도 트랙으로 검토)
