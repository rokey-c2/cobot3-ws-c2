## 시행 전 확정할 사항

- [ ] TEAM_ACCESS.md의 실제 현재 사용 가능자 및 계정 확정
- [ ] 적용 대상 코드·문서·이미지의 경로/버전 및 권리자 확인
- [ ] 과거 기여자의 권리, 교육 과정 협약, 업무상 저작물·양도 여부 확인
- [ ] 기존 Apache-2.0 및 외부 자료의 예외 범위 확인
- [ ] 필요한 모든 권리자의 동의 근거 확보
- [ ] 시행일과 최종 확정 커밋 기록

동의는 실제 권리자 또는 적법한 대리인의 것이어야 합니다.
README 이름, 관리자 권한, 단순 PR 승인 또는 미응답만으로 동의를 간주하지 않습니다.
공개 문서에는 서명·연락처 등 민감한 정보를 게시하지 말고 확인 가능한 비공개 기록의
식별 정보만 남길 수 있습니다.

| 적용 경로/버전 | 권리자 또는 권한 있는 대리인 | 동의 근거 | 확인일 |
|---|---|---|---|
| 미확정 | 미확정 | 미확보 | 미확정 |
