## 2. 규격 통일 (이 Linux 머신, ffmpeg) — CapCut 넘기기 전

최종 타임라인 = **1920×1080 / 30fps / H.264 / 무음**.

```bash
cd /home/rokey/main_ws/cobot3-ws-c2
mkdir -p video/norm

# 구간 고르기: 프록시 스크럽
mpv video/proxy_amr_scene_01.mp4

gifcut () {  # $1=in.gif(docs/)  $2=out이름  $3=시작초  $4=길이초
  ffmpeg -y -i "docs/$1" -ss "$3" -t "$4" \
    -vf "fps=30,scale=1920:1080:force_original_aspect_ratio=increase,crop=1920:1080,setsar=1,format=yuv420p" \
    -an -c:v libx264 -preset medium -crf 18 "video/norm/$2.mp4"
}

# 몽타주 3초 → 여유롭게 4초 뽑고 CapCut에서 트림. START는 스크럽으로 확정
gifcut amr_scene_01.gif  m2_amr_drive   120  4
gifcut arm_scene_01.gif  m5_arm_pnp      90  4
gifcut cb_scene.gif      m6_conveyor      8  4
```

- 레터박스가 낫다면 `crop=1920:1080` 대신
  `force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2:black`.
- 실채널 캡처본(mp4)·SIM 녹화·웹 녹화도 같은 vf 규격으로 통일해서 `video/norm/`에.

## 3. CapCut 편집

### 3-1. 프로젝트
- 새 프로젝트 → **1080p / 30fps / 16:9**
- 트랙 구성: 메인 트랙(몽타주 + 6a/6b), 그 위에 연속 줌 시퀀스용 컴포지션

### 3-2. 6채널 몽타주 (1번, 0:00–0:18)
- 6클립을 순서대로, 각 3초, **하드컷** (전환 효과 금지)
- **CCTV 룩** (6클립 동일):
  - 내장 효과 "CCTV / 监控" 또는 "Camcorder / VHS" 강도 40~60%, 또는
  - 조정: 채도 −40~−55 / 대비 +8~+12 / 밝기 −5 / 그레인 +30~+45 / 비네트 +30~+50
  - 한 클립 세팅 → **서식 복사 → 나머지 5개 붙여넣기**
- **타임스탬프**: 텍스트 `CAM 01 · 09:42:11` (채널마다 `CAM 01`~`CAM 06`, 시각 몇 초씩 이어지게),
  우상단, 모노스페이스, 배경 검정 45%. `video_ai_brief.md`상 자막 아님(CCTV UI라 허용)

### 3-3. 연속 줌 시퀀스 (2~5번, 0:18–0:32)

레이어 구조 (아래→위):
1. **사무실 플레이트** (애니메 남자, 듀얼모니터, 뒷모습) — 생성형 AI 클립
2. **관제 화면** — 실제 대시보드 스크린샷 위에 몽타주 추가 3채널(2·5·6번 클립)을 패널 위치에
   맞춰 얹은 6패널 합성 (4장). 이걸 사무실 플레이트의 **오른쪽 모니터 화면 영역에 원근 맞춰 배치**
3. **알림 카드** 2장 (3-4 참고)

키프레임 (한 컴포지션에서 Scale/Position 램프):
- 0:18 시작: 관제 화면 레이어를 **6번 패널만 화면 꽉 차게** (Scale ~600%, 6번 패널 중심으로 Position)
- 0:18→0:20: Scale 축소 → 6패널 관제 화면 전체가 프레임에 (Scale 100%) — **줌아웃①**
- 0:20→0:23: 계속 축소 → 관제 화면이 오른쪽 모니터 안으로 들어가고 사무실 플레이트가 드러남
  (관제 레이어 Scale/Position을 모니터 화면 영역 크기·위치로) — **줌아웃②**
- 0:23→0:26: 정지에 가깝게 홀드. 이 구간에 알림 카드 슬라이드-인 + (플레이트에 고개 돌림 동작이
  없으면 남자 레이어를 살짝 회전/교체해 시선 이동 암시)
- 0:26→0:30: 알림 카드 2장을 별도로 **화면 중앙에 크게** 오버레이 (플레이트 위에 풀사이즈)
- 0:30→0:32: 역방향 Scale 램프 → 관제 화면이 다시 프레임 꽉 차게 — **줌인**
- 0:32 하드컷 → 6a

> 원근 합성: 오른쪽 모니터가 정면이 아니면 관제 레이어에 CapCut의 3D 회전(또는 코너 핀 계열
> 효과)으로 살짝 기울여 모니터면에 맞춘다.

### 3-4. 알림 카드 (4′, 0:26–0:30)
생성형 AI에 문구를 맡기지 않고 **CapCut 텍스트 레이어**로:
- 카드 1: `Conveyor STOP` — 굵은 산세리프, 흰 배경 카드 + 빨강 아이콘 점, 텍스트 `#1F2937`
- 카드 2: `Urgent delivery 발생` — 같은 스타일, `Urgent` 또는 전체를 주황 `#F59E0B` 강조
- 두 장을 위아래로 쌓거나 순차로(카드1 → 0.5초 후 카드2) 슬라이드-인
- 한글 폰트: 본고딕/Pretendard Bold

### 3-5. 실제 관제 조작 (6a·6b, 0:32–1:00)
- 6a: `/amr` Jog로 AMR을 우선순위 위치로 이동시키는 SIM 녹화. 주소창 보이게.
- 6b: 대시보드에서 `MAIN_CONVEYOR` STOP(빨강) 상태 → **START** 클릭 → RUNNING(초록). 주소창 보이게.
- 둘 다 실제 화면 녹화 그대로, 하드컷. CCTV 룩 **적용 안 함**(여기부터는 실제 관제 톤).
- 엔딩 = 6b의 RUNNING 초록 상태에서 정지.

### 3-6. 내보내기
- 1080p / 30fps / H.264 / mp4, 비트레이트 권장 이상(수동 12~20Mbps), 오디오 없음
- **CapCut 무료판 워터마크 확인**: 템플릿/인트로/일부 효과·폰트·스티커에 붙음. export 후 확인
- 검수: `ffprobe -v error -show_entries format=duration -of default=nw=1 demo_final.mp4` → 60.0 ±0.5

## 4. 6패널 관제 화면 합성 (ffmpeg, 줌 시퀀스 바탕)

실제 3채널 대시보드 스크린샷(`dash.png`, 1920×1080)에 추가 3채널(2·5·6번 몽타주 클립)을
빈 패널 자리에 얹는다. **패널 좌표는 스크린샷 실측 후 채움.**

```bash
ENC="-an -c:v libx264 -preset medium -crf 18 -pix_fmt yuv420p -r 30"

# 예시: 추가 3패널을 각각 (X,Y) 위치에 W×H로 오버레이
ffmpeg -y -loop 1 -i dash.png \
  -i video/norm/m2_amr_drive.mp4 -i video/norm/m5_arm_pnp.mp4 -i video/norm/m6_conveyor.mp4 \
  -filter_complex "\
  [1:v]scale=W:H,setsar=1[p1];[2:v]scale=W:H,setsar=1[p2];[3:v]scale=W:H,setsar=1[p3];\
  [0:v][p1]overlay=X1:Y1[a];[a][p2]overlay=X2:Y2[b];[b][p3]overlay=X3:Y3[v]" \
  -map "[v]" -t 15 $ENC video/panel6.mp4
```

- 실제 대시보드 UI가 6타일 그리드를 지원하지 않으면(3타일만), 스크린샷의 스타일을 살려
  2×3 그리드를 목업으로 만들어 바탕으로 써야 함 → **스크린샷 받은 뒤 판단**.
- 이 `panel6.mp4`를 CapCut 3-3의 "관제 화면" 레이어로 사용.
